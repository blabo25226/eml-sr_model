## 1. 純 EML モードとは

**純 EML モード**は、唯一の関数プリミティブ

$$\mathrm{EML}(x, y) = e^{x} - \ln(y)$$

と算術接着 (Plus, Times, Neg, 定数) **だけ**でデータ $(X, y)$ から数式 $y \approx f(x_1, \dots, x_d)$ を発見する探索モードである。`Searcher(pure_eml=True)` で起動する。

### フル版 (通常の fable) との違い

| | フル版 fable | 純 EML モード |
|---|---|---|
| 関数プリミティブ | EML, exp, log, sin, cos, sqrt, pow, abs, sigmoid, min, max … (~20 種) | **EML のみ** |
| 閉形式ステージ (Stage A/A2/C) | 使う (精度の主力) | **一切通らない** |
| 探索の主力 | 変換 × 単項式和の線形代数 | EML ユニットの線形結合 + EML 文法ビーム |
| 発見式に EML が出るか | ほぼ出ない (実測 0/99) | **明示的に出る (実測 79/99)** |
| Feynman 99 式 (1% ノイズ) | 71/99 | 31/99 |
| 狙い | 精度最大化 | **EML の解釈可能性・原初思想の実証** |

両モードは同一エンジンに `pure_eml` フラグで共存する。開発の動機は「フル版では EML を組み合わせる原初の仕組みが空洞化していた (採用式 0/99)」ことへの回答で、EML を主役に据え直すとどこまで精度が出るかを実証するために作られた。

## 2. 理論的基礎 (数式込み)

### 2.1 なぜ EML だけで十分な表現力が出るのか

EML 単独では加算も乗算もできない。そこで算術接着 (Plus/Times/Neg/定数) を許すと、標準的な初等関数がすべて **EML の合成**として書ける:

$$e^{u} = \mathrm{EML}(u, 1), \qquad \ln v = 1 - \mathrm{EML}(0, v), \qquad \frac{1}{v} = e^{-\ln v} = \mathrm{EML}\bigl(\mathrm{EML}(0, v) - 1,\ 1\bigr)$$

したがって指数・対数・べき・除算はすべて純 EML 文法の内部で表現される。発見式には EML・Plus・Times・Neg・変数・数値以外は現れない (実測で禁止演算子の混入ゼロを確認済み)。

### 2.2 中心命題 — 1 つの EML ユニットが覆うクラス

EML ユニット $\mathrm{EML}(P, Q)$ の第 1 引数に **log 拡張アフィン形式**

$$P(\mathbf{x}) = a_0 + \sum_i a_i x_i + \sum_{i \in \mathrm{pos}} b_i \ln x_i$$

を与える ($\ln x_i$ は上記のとおり $1 - \mathrm{EML}(0, x_i)$ で純文法内)。すると

$$e^{P} = \underbrace{e^{a_0}}_{C} \cdot \prod_i x_i^{\,b_i} \cdot e^{\sum_i a_i x_i}$$

となり、**1 ユニットの第 1 引数だけで「単項式 × 指数」クラス全体**を覆う。これはフル版の Stage A が log 変換で解いていたクラスに相当する。第 2 引数の $-\ln Q$ が対数・logit 型を覆う。

さらに**入れ子 EML ユニット**

$$c \cdot \exp\!\Bigl(\sum_j b_j \ln x_j + a_1 \underbrace{e^{\sum_i c_i \ln x_i}}_{M(\mathbf{x}) = \prod_i x_i^{c_i}}\Bigr)$$

を許すと、「単項式 × 指数-of-単項式比」($n_0\, e^{-mgx/(k_bT)}$ の族) まで表現できる。

### 2.3 理論的限界

EML $= e^x - \ln y$ は**単調・非振動**関数である。$\sin, \cos, \arctan$ のような**振動構造は実数の EML では原理的に構成できない**。Feynman 99 式のうち三角関数を含む 14 式は純 EML モードでは到達不能で、これがモードの理論上限 (~85/99) を規定する。この限界はアルゴリズムの工夫ではなくプリミティブ選択に由来する。

## 3. アルゴリズム — 2 つの機構と最終選択

> **よくある誤解への回答:** 「全予測は $f = c_0 + \sum_k c_k\,\mathrm{EML}(P_k, Q_k)$ の形で計算しているのか?」
> → **いいえ。** その加法形は下記の機構 1 の出力であり、機構 2 (ビーム探索) は加法形とは限らない任意の EML 木を出す。両方の候補から検証誤差で最良 1 式を選び、その式で予測する。

### 3.1 機構 1 — EML 基底ブースティング (加法形・線形回帰的)

$$f(\mathbf{x}) = c_0 + \sum_{k=1}^{K} c_k \, \mathrm{EML}(P_k, Q_k)$$

を残差ブースティングで組み立てる。**外側の係数 $c_k$ は最小二乗 (OLS) — つまり線形回帰**である。ただし基底関数 $\mathrm{EML}(P_k, Q_k)$ 自体を固定せず、その引数 $P_k, Q_k$ を**データから Levenberg-Marquardt (LM) で 1 つずつ学習して足していく**。統計でいう **射影追跡回帰 (projection pursuit) / 基底関数ブースティング**に当たり、基底を固定する通常の線形回帰とは異なる。

各ステップの流れ:

1. 現在の残差に相関する変数を選ぶ (高次元でも引数を小さく保つ)
2. 構造バリアントを個別に候補化 — **純単項式** ($\ln$ のみ)、**アフィン指数** ($x$ のみ)、**ガウス族** ($x + x^2$, 例 $e^{-x^2/2}$)、**混在**、**入れ子 EML** ($n_0 e^{-mgx/k_bT}$ 族)。構造を分けるのは、混在引数だとノイズ下で純単項式の係数がスナップできず真の法則に戻れないため
3. 各候補を log 空間初期化 + 多スタート LM でフィット
4. 外側 $c_k$ を OLS で解いて全体を組み、**検証分割 (80/20) の誤差が改善する候補のみ**採用 (過学習防止)
5. 定数スナップ (悪化しない場合のみ整数・単純値へ丸め) → 純文法のリテラルへ実体化

### 3.2 機構 2 — 純 EML 文法ビームサーチ (任意木)

演算子を $\{\mathrm{EML}, \mathrm{Plus}, \mathrm{Times}, \mathrm{Neg}\}$ に制限したレジストリ上で、複雑度 $k = 1, 2, \dots, 10$ の式木を幅 `beam_width` のビームで構成的に列挙する (フル版の改良ビーム機構を流用)。演算子が 4 種しかないため分岐係数が小さく、同じビーム幅でより深い複雑度に届く。

- 出力は加法形とは限らない。実例:
  - `Plus(Times(v0, v1), c)` — 純粋な積 (EML を使わない、I.12.1)
  - `Times(v0, EML(EML(C, v1), C))` — 真の入れ子 EML (I.29.4)
- **ラッパー先読み採点**: 候補 $f$ を $\min_g \min_{a,b}\mathrm{RMSE}(y,\,a\,g(f)+b)$、$g \in \{\mathrm{id}, e^u, \ln|u|, 1/u\}$ でランキング。部分式が「もう一段 EML を被せれば効く」場合に育つ前に刈られるのを防ぐ (ランキング専用で誤差の意味は不変)
- **挙動多様性キャップ**: 正規化予測ベクトルの量子化シグネチャでバケット化し、似た振る舞いの変種でビームを埋めない
- **ビーム幅再拡張**: 時間予算が余りフロントが停滞したら幅を 2 倍にして継続

### 3.3 後段と最終選択

両機構の候補を**共通の Pareto front (誤差 × 複雑度)** に集約し、

1. 残差ブースティング (最良候補の残差に機構 1 を再適用、検証改善時のみ受理)
2. 原空間 LM ポリッシュ (上位候補の全定数を生の $y$ に対して再最適化)
3. **検証誤差の 1 標準誤差則ランキング** (訓練誤差でなく held-out 誤差で並べ、最良から 1SE 帯内は最小複雑度を優先) — 過学習候補をここで落とす

を経て**最良 1 式**を選ぶ。予測はその 1 式を RPN スタックマシンで評価する。つまり各予測は「勝った 1 本の式」で行われ、それが加法形のこともあれば純粋な単項式や入れ子 EML のこともある。

## 4. 使い方 (Python)

セットアップ (ビルド・インストール) はフル版マニュアル `manual_eml-sr_fable.md` の §2 と共通。

### 4.1 クイックスタート

```python
import numpy as np
import eml_sr_fable

# 例: y = 3 e^{-2 x0} + 1 (真の式は未知という想定)
rng = np.random.default_rng(0)
X = rng.uniform(0.5, 3.0, size=(500, 2))
y = 3.0 * np.exp(-2.0 * X[:, 0]) + 1.0

searcher = eml_sr_fable.Searcher(
    pure_eml=True,           # ← 純 EML モードを有効化
    max_complexity=10,       # 演算子4種なので深めに (フル版は6)
    beam_width=1000,
    time_budget_s=110.0,
    early_exit_threshold=9e-3,   # ノイズがあるデータでは 9e-3 程度
    verbose=False,
)

candidates = searcher.find_candidates(X.tolist(), y.tolist())

# 節約的タイブレーク: 最良誤差の5%帯内で最小複雑度の候補を選ぶ
scored = []
for c in candidates:
    p = np.asarray(c.predict(X.tolist()), dtype=float)
    r = float(np.sqrt(np.mean((y - p)**2))) if np.all(np.isfinite(p)) else np.inf
    scored.append((c, r))
best_rmse = min(r for _, r in scored)
band = [(c, r) for c, r in scored if r <= best_rmse * 1.05]
best, _ = min(band, key=lambda cr: (cr[0].complexity, cr[1]))

print(best.formula)   # 例: Plus(Plus(-0.29, Times(1.12, Times(1.16, EML(Plus(...))))), ...)
print("EML を含む:", "EML(" in best.formula)   # True
```

発見式には `EML(...)` が明示的に現れる (これがモードの狙い)。`v_{i}` は第 i 列の変数。数値評価は `best.predict(X.tolist())` / `best.eval_batch(X)` を使う。

### 4.2 主なパラメータ (純 EML モードで意味を持つもの)

| パラメータ | 推奨 | 意味 |
|-----------|------|------|
| `pure_eml` | `True` | 純 EML パイプラインに分岐 (A/A2/C を通らない) |
| `max_complexity` | 10 | ビームの複雑度上限。演算子4種なので深めが有効 |
| `beam_width` | 1000 | ビーム幅 |
| `time_budget_s` | 110 | 1 探索の時間予算 (秒)。基底 ~30s + ビーム + 幅再拡張 |
| `early_exit_threshold` | 9e-3 (ノイズ時) / 1e-9 (クリーン) | ノイズ床以下を追わない |

内部で自動設定されるもの: 純 EML モードでは先読み採点 (`lookahead_scoring`) と挙動多様性 (`behavior_cap`) がビーム段で有効化される。基底ブースティングは `pure_basis_stage` (既定 True、アブレーション用に False にできる)。

### 4.3 フル版との使い分け

- **精度が最優先** → フル版 (`pure_eml=False`)。Feynman 83/99、有理式・三角も可
- **EML の解釈可能性・原初思想の式が欲しい / EML 表現に意味がある応用** → 純 EML モード
- 三角関数を含むデータ → フル版必須 (純 EML では原理的に不可)

## 5. 実績と限界

すべて `results/eml_sr_pure_feynman_test1_results.json` に生データがある。

### 5.1 Feynman 物理方程式 99 式 + 1% ガウシアンノイズ

| 系 | 条件 | 完全回収 |
|----|------|---------|
| **純 EML モード** | 1% ノイズ・EML+算術接着のみ | **31/99 (ok+partial 51/99)** |
| (参考) 原初 first_AI | クリーン・純ビーム | 9/99 |
| (参考) 原初 cursor | クリーン・純ビーム | 13/99 |
| (参考) フル fable v5 | 1% ノイズ・A/A2/C+ビーム | 71/99 |

- **原初系 (9/13) の 2.4〜3.4 倍を、より難しいノイズ付き条件で達成**。「原初の EML 機構を工夫すれば精度は上げられる」ことを実証
- **採用式 79/99 に `EML(…)` が明示的に出現** (フル版の 0/99 に対して)、純文法違反ゼロ
- 総時間 187 分 (99 式)

### 5.2 アブレーション (基底ブースティングの寄与)

| 構成 | 一般ベンチ 20 | Feynman 層化 30 |
|------|--------------|-----------------|
| 純 EML ビームのみ (基底 off) | 6/20 | 4/30 |
| 純 EML フル (基底 + ビーム) | 7/20 | 7/30 |

基底ブースティングが Feynman30 で +3・一般で +1 の寄与。列挙 (ビーム) では複雑度上限に阻まれる「単項式 × 指数」クラスを、パラメトリック展開 + LM が直接回収する。

### 5.3 特筆点

- **I.40.1** ($n_0 e^{-mgx/(k_bT)}$) は入れ子 EML ユニットでクリーン誤差 $1.5\times10^{-1} \to 1.8\times10^{-3}$。これは**フル fable v5 が failed だった式**で、純 EML が特定の式でフル版を上回る例
- 加法形で回収された例: I.6.2a ($e^{-\theta^2/2}$)、I.12.2 ($q_1 q_2/4\pi\varepsilon r^2$)
- ビーム木で回収された例: I.12.1 ($q_1 q_2$, 純粋な積で EML なし)、I.29.4 (入れ子 EML)

### 5.4 限界

- **三角関数を含む 14 式は原理的に不可** (振動構造は実数 EML で表現不能)。理論上限 ~85/99
- 三角以外の失敗 29 式は有理式・Lorentz 族など。純 EML でも入れ子 EML による有理近似は可能だが、ノイズ下では基底の LM が真の分母構造まで到達しきれず partial 止まり
