## 考察 (ノイズの影響: test3 との差分)

### 総括: 27/28 → 25/28、変数特定は 10/10 を維持

1% ガウシアンノイズで失われたのは **A7 (x^1.7) と A8 (Hill 式) の 2 式のみ**
(いずれも partial に降格)。B2 はノイズなしでも partial。
**スパース性 (C) は 10/10 のまま一切劣化せず、変数特定も 10/10 を維持**した。

### ノイズで失われた 2 式の共通点 — 連続指数の推定がノイズに敏感

- `A7 = x^1.7`: ノイズなしでは三分探索リファインが指数 1.7 に厳密到達したが、
  ノイズ床 (σ=0.032) では指数の尤度面が平坦化し、多項式和
  (−1.18√x + 0.42x² + 1.48x + 0.28) の近似が同水準の訓練誤差になる。
  test RMSE 9.4e-3 は σ 比例閾値 (ok < 0.15σ = 4.8e-3) を超え partial。
- `A8 = Hill 式`: 同様に有理閉形式の回収がノイズで崩れ、多項式+trig の和で近似
  (test RMSE 3.4e-3 > 閾値 1.4e-3)。
- 過去の test1_v4 (Feynman+ノイズ) で観察された「変換系 (InvY/InvY2) のノイズ増幅」
  と同型の現象で、v4 演算子固有の弱点ではない。

### ノイズ下でも保たれたもの

- **離散構造 (Min/Max/Abs) はノイズに頑健**: A9 = `0.9998·Min(v2, v0·v1) + 0.0007`、
  C7 = `1.0001·Min(v8, v0·v3) + 0.00004` など、構造は厳密なまま係数だけが
  ノイズ分揺れる形で全回収。折れ線・角のある構造は 1% ノイズでは崩れない。
- **スパース性の変数特定は完全維持**: 高次元 (a=20, 25) でも無関係変数の混入なし。
  検証分割 (80/20) による項剪定がノイズ追随項を排除する設計が機能している。
  C 系の実行時間は増加 (例: C10 12.9s → 121.3s) — 早期終了がノイズ床で
  発火しにくくなり探索を使い切るため。

### 残課題

1. **z·sigmoid(x−y) 型のゲート構造** (B2): ペア特徴 SigmoidDiff(i,j) の追加で
   閉形式回収が可能になる見込み。
2. **ノイズ下の連続指数推定** (A7/A8): 指数リファインの目的関数を検証分割誤差に
   切り替える、または指数候補への事前分布 (単純な値を優先) の導入が対策候補。
