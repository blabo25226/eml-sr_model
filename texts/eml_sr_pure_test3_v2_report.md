## 考察 — 純 EML の適性が構造クラスで綺麗に分かれた

### 総括: 4/28 ok (A 0/9・B 0/9・C 4/10)、変数特定 C 6/10

フル版 v5 の 25/28 に対し大幅に低いが、**これは test3_v2 が v4 の新演算子
(abs/sigmoid/min/max) を検証するために設計されており、A/B の 18 式が
まさに純 EML の苦手構造 (非平滑・振動) で占められているため**である。
つまり本ベンチは純 EML にとってほぼ最悪ケースであり、意味のある信号は
C (スパース性・単項式/和) セクションに現れる。

### 構造クラス別の明確な分離

| 構造 | 例 | 純 EML の結果 |
|------|-----|--------------|
| **純単項式・単項式比** | C2 (x₂x₅/x₆), C10 (5変数積/25次元) | **ok・変数特定 ✓** |
| **交互作用の和 (積の和)** | C4 (x₁x₂+x₃x₄+x₅), C9 (x₁x₈+x₂x₅) | **ok・変数特定 ✓** |
| **連続べき・高次元単項式** | C8 (x₃^1.5·x₆), C3/C5 (4-6変数/20次元) | partial (変数特定は概ね ✓) |
| **abs / min (非平滑)** | C6 (\|x₂−x₇\|), C7 (min), A1-A4, A9 | **failed** (実数 EML で表現不能) |
| **sigmoid ゲート** | C1, A5/A6, B2/B3 | failed〜partial (入れ子で近似だが精度不足) |

- **乗法的交互作用 (単項式) と加法的交互作用 (積の和) は純 EML の得意領域**で、
  高次元 (C10: 25 変数中 5 変数) でも回収・変数特定に成功
- **abs/min/max/sin 等の非平滑・振動構造は原理的に不可** — これがモードの限界を規定
- 変数特定の失敗 4 件 (C1, C3, C6, C7) は sigmoid/abs/min/高次元に集中。
  **純 EML が表現できる構造 (単項式・和) に限れば変数特定は良好**

### 応用上の含意 (交互作用発見・変数選択)

C4 = x₁x₂ + x₃x₄ + x₅ (2 次交互作用の和) と C9 = x₁x₈ + x₂x₅ を
**係数・変数とも正しく回収**した点は、GWAS のエピスタシス (遺伝子間交互作用) や
PK の薬物相互作用の「効く少数変数の乗法的組み合わせ」を発見する用途に直結する。
発見式の単項式の指数ベクトルから、どの変数が何次で交互作用するかが読める。
一方、閾値応答 (sigmoid ゲート) や折れ線 (min/abs) を含む相互作用は純 EML では
取れないため、そうした構造が想定される場合はフル版 fable か他ツールが必要。

### フル版 (v5: 25/28) との対比

純 EML が落とした 21 式のほぼ全ては A/B の abs/sigmoid/min/max/sin 系で、
これらはフル版では専用演算子 (v4 拡張) が担っていた。**純 EML の価値は
「精度」でなく「EML+算術接着だけで乗法・加法交互作用クラスを解釈可能に回収する」
点にあり、本結果はその境界を定量的に示している。**
